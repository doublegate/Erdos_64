# `erdos64` — Hashimoto Trace Identities, Cage Cycle Counts & Lean 4 Arithmetic Checks for Erdős Problem #64 (Erdős–Gyárfás; open)

> [!WARNING]
> **Status (2026-11-03): Erdős Problem #64 (Erdős–Gyárfás) remains open. The claimed resolution in this repository is withdrawn.**
>
> An independent review found that the main argument does not hold:
> - **The reduction from minimum degree 3 to cubic graphs is not proved.** The triangle-contraction step is also invalid: a 2^j-cycle through the contracted vertex lifts only to cycles of length 2^j + 1 or 2^j + 2.
> - **The spectral step (Theorem 2.10, Corollary 2.11) carries no cycle information.** It assumes Tr(B^(2^k)) = 0, which having no simple 2^k-cycle does not imply. Its conclusion, Tr(B^(2^(k+1))) > 0, holds for every cubic graph in the claimed range, because non-simple walks dominate the trace. Bounding those walks is the actual problem, and it is not done.
> - **The k = 3 case rests on checks of about 30 specific graphs.** A Lean docstring states a false determinant formula (counterexample: the Tutte 12-cage).
> - **The Lean 4 files check integer arithmetic and two explicit 8-cycles.** Several theorems take the key inequality as a hypothesis, and no Lean statement mentions the conjecture.
>
> What stands: the trace polynomials and variance identities, and cycle counts for specific graphs (Petersen, Heawood, McGee, Tutte–Coxeter and others). The manuscript, explainer, tables and scripts below are kept unchanged for reference. Read every "closure" or "resolution" claim in them as withdrawn.

> **Erdős Problem #64 (1,000 USD Prize — Posed by Paul Erdős & András Gyárfás, 1995):**  
> <i>Does every finite simple graph $G$ with minimum degree $\delta(G) \ge 3$ contain a simple cycle of length $2 ^ k$ for some integer $k \ge 2$ (i.e., of length $4, 8, 16, 32, \dots$)?</i>  
> Reference: [`https://www.erdosproblems.com/64`](https://www.erdosproblems.com/64)

`erdos64` (`v0.2.0`) is a self-contained Rust + CUDA research crate, 17-theorem zero-`sorry` Lean 4 (`v4.33.1`) formalization (`#L79`–`#L321`), independent Python + SymPy verification suite, and publication manuscript investigating and resolving **Erdős Problem #64** (the Erdős–Gyárfás $2 ^ k$-Cycle Conjecture) via **Multi-Octave Chebyshev–Hashimoto Spectral–Topological Discharging Closure**.

## Quick Start & Verification Commands

```bash
# 0. Verify 17-theorem zero-sorry Lean 4 (v4.33.1) formalization (#L79–#L321)
lake --wfail build
lake env lean Erdos64/AxiomCheck.lean
lake env lean FormalConjectures_64.lean

# 1. Format, lint, and run CPU unit tests
cargo fmt --check
cargo clippy --all-targets -- -D warnings
cargo test --release

# 2. Run CUDA GPU bit-exact parity tests (on hosts with an NVIDIA GPU)
cargo test --release -- --ignored
cargo run --release -- gpu-parity

# 3. Certify all 18 canonical (3,g)-cages and snarks (Theorem 2.1 & 3.1)
cargo run --release -- certify-cages --max-full-n 24

# 4. Certify Open-Frontier (50 <= n <= 62) lifts (Theorem 2.2)
cargo run --release -- certify-frontier

# 5. Certify Phases 3–9 Commutator Floor, Spectral Doubling, Topological N_16, Order-10/12/14 Bessel Cascade, Multi-Octave Discharging Closure & Tabu C_16-Minimizer (Theorems 2.3–2.10 & 3.2)
cargo run --release -- certify-phase3 --restarts 8 --steps 250

# 6. Run independent Python + SymPy verifiers and regenerate manuscript figures
python3 scripts/verify_erdos_gyarfas_cages.py
uv run --with sympy --with numpy python3 scripts/verify_phase5_topological_n16.py
uv run --with sympy --with numpy python3 scripts/verify_phase6_b10_hankel.py
uv run --with sympy --with numpy python3 scripts/verify_phase7_b12_deg2_bessel.py
uv run --with sympy --with numpy python3 scripts/verify_phase8_b14_deg3_bessel.py
uv run --with sympy --with numpy python3 scripts/verify_phase9_multi_octave_closure.py
uv run --with sympy --with numpy python3 scripts/verify_erdos64_theorems.py
uv run --with sympy python3 paper/anc/verify_erdos64_chebyshev_hashimoto_closure.py
uv run --with matplotlib --with numpy python3 scripts/generate_figures.py
```
